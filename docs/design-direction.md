# Little Days 1.1 设计方向

让用户自己的纸面成为视觉中心：照片、文字、原创植物贴纸与留白一起讲述一天。编辑器保持安静、清楚，风格由用户继续调整。设计依据与来源记录在 [设计调研](design-research.md)，流行度快照只用于参考，不是传播效果或“出圈”的保证。

## 纸面与操作

- 配色：墨色 `#373d32`、橄榄绿 `#5d6c4d`、桌面 `#eeefe8`，以暖纸 `#f8f5ec`、鼠尾草 `#eef0e5`、玫瑰 `#f6eeea` 等预设建立初始气质。允许自定义纸色，调整时保持深色文字可读。
- 字体：控件使用系统无衬线与清晰的中文标签，纸面使用 Georgia / Songti SC / Noto Serif CJK SC 等本机字体，不请求远程字体。
- 工作区：日期与日记导航在左，纸页在中间，文字、素材与 AI 创作工具在右。窄屏收起资料库，并让工具移动到纸页下方。
- 反馈：拖动与键盘调整立即可见；保存成功必须对应真实 IndexedDB 事务提交。静止时不循环播放装饰动画，旋转主要服务于纸片与照片的拼贴感。

## 模板是起点

12 款原创模板分为日常、旅行、心情和创意四类，从盐系、胶片、书信、小刊延伸到明信片、植物观察、小票、拍立得、画廊、夜晚、软糖与留白。它们提供不同的文字和照片关系，切换时保留已有照片与文字，并支持撤销。

标题与正文都是可调整的文字区域：用户可以移动位置、修改宽高、字号和对齐，正文另有行高设置。照片、文字素材、胶带和贴纸也保持独立可编辑。正文最多 1200 字符，但任意版式不一定都能装下全部内容；界面和导出应明确提示溢出，方便用户扩大区域、调小字号或在同一天续写。

记录可以短，也可以慢慢写。产品不设置连续打卡、积分或每日完成压力；同一天可以拥有多页，自由纸色和排版让不同回忆保留自己的样子。编辑器、PNG 导出与 JSON 备份应忠实保留这些选择。

## AI 作为可选创作搭子

AI 面板帮助改写、排版、配色和整理素材方案。用户选择兼容 API 与模型，主动发送请求；默认只发送对话，勾选后才附带本页文字与布局。照片不发送，模型不能看图，也不能假装理解照片中的人和物。内置功能不生成图片，可选 [创作 Skill](creator-kit.md) 提供独立的外部素材流程。

提案先校验、显示预览，再由用户明确应用；应用后可以撤销。生成期间原页若已变化，不覆盖用户的新修改。Key 仅在当前页面内存中保留，普通编辑无需配置 API。使用 AI 需以 `npm run dev` 启动本机代理，纯静态托管只提供编辑功能。详见 [AI API 边界](ai-api.md)。

目前 AI 链路只用 mock 验证交互和接口边界，没有真实模型调用、模型 token 或付费实验；不据此声称生成质量、延迟或服务可用性已获验证。

## 来源与原创

项目参考纸艺、拼贴与小刊的一般创作方法，具体代码、模板、贴纸和项目 Skill 独立编写。不复制受限第三方 Skill 的提示词、样图或素材；示例照片另按 [第三方来源](../THIRD_PARTY.md) 标注。设计判断可以继续迭代，用户的日记、照片与编辑权始终保留。
